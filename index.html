Configure su API key

Para responderle necesito una API key gratuita de Google Gemini. Toma un minuto y se guarda solo en este dispositivo.

  1. Abra aistudio.google.com/apikey e inicie sesión.
  2. Toque «Create API key» y cópiela.
  3. Péguela en Configuración y toque «Probar conexión».

PERFIL

VOZ

En iPhone, el dictado necesita Siri y Dictado activados en Ajustes (General › Teclado › Activar dictado). Si un idioma no está disponible, probaré con el siguiente.

Este navegador no permite dictado por voz; puede usar el micrófono del teclado.

MANOS LIBRES Y COMODIDAD

Solo funciona con Antares abierto y en pantalla: se pausa al bloquear, al cambiar de app o mientras Antares habla. Funciona mejor en Chrome para Android.
