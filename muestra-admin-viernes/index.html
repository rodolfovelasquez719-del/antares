🪐 Antares · Administrar Viernes (muestra)

Desde aquí usted prepara la app Viernes de Wendy. Ella no ve ninguna configuración: solo escanea el código o abre el enlace una vez.

1. Key de Gemini

Se usa solo para crear el enlace. No se guarda en ningún servidor ni en GitHub. Recomendado: crear una key aparte para Wendy en aistudio.google.com/apikey, así su uso no gasta la cuota de Antares.

3. Enlace y código QR

En el Android de Wendy: abrir la cámara (o Google Lens) → apuntar a este código → tocar el enlace → se abre Viernes en Chrome y queda lista ("¡Listo! Viernes quedó preparada 💜"). Luego en Chrome: menú ⋮ → Agregar a pantalla principal / Instalar app.

⚠️ El enlace contiene la key (en la parte "#", que no se envía a GitHub). Es preferible mostrar el QR en pantalla; si lo envía por WhatsApp, borre el mensaje después. Viernes borra la key de la barra de direcciones al abrirse.
